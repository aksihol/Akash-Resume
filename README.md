## 🌟 Features

- **Luxury Modern Aesthetic**: Designed with a dark editorial luxury theme, warm gold accents, and fluid glassmorphism.
- **Theme Engine**: Complete **Dark**, **Light**, and **System Auto** themes with high-contrast typography.
- **Interactive QA Terminal Simulator**: Built-in CLI simulator supporting interactive commands (`qa help`, `qa run-suite`, `qa skills`, `qa projects`, `qa contact`, etc.).

  - **HINCOL** — Bitumen Derivatives Web & Mobile Application (Publicis Groupe)
  - **Citroën** — Automobile Customer Experience Platform (Publicis Groupe)
  - **Redington** — Enterprise B2B E-Commerce Platform (Publicis Groupe)
  - **Freight Club** — Freight Logistics Management Platform (QualiteSoft)
  - **Cymax** — Online Furniture Retail E-Commerce (QualiteSoft)
- **STLC & Agile QA Lifecycle**: 6-stage testing protocol matrix and core QA competency cards.
- **ATS-Optimized Printable Resume ([`resume.html`](resume.html))**: Clean, high-density, printable resume with dedicated `@media print` styling for 1-click PDF export.
- **Multi-Device Responsiveness**: Seamless experience optimized for mobile phones (320px–480px), tablets (768px–1024px), laptops, and 4K displays.
- **Command Palette (`Ctrl + K` / `Cmd + K`)**: Quick keyboard-driven navigation across all portfolio sections and features.
